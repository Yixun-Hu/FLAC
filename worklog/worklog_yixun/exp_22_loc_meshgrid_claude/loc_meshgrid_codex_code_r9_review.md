A different valid audit/manifest or hand-assembled, non-merged directory can therefore be reported as P1, bypassing merge-only declared-room, advisory-batching, and `source_rows` gates.

2. **BLOCKER — partial or duplicated G1 query sets can produce canonical metrics.** Only room names are compared at [`meshgrid_report.py:1159`](/home/yixunhu/codespace/FLAC/src/localization/meshgrid_report.py:1159). Evaluation then iterates whatever queries G1 contains at [`meshgrid_report.py:1170`](/home/yixunhu/codespace/FLAC/src/localization/meshgrid_report.py:1170), without a final equality check against the 5,337 D1/row identities. A 5,336-query G1 plan yields partial metrics while the report census still says 5,337; duplicated G1 entries are double-weighted. The fixture’s deliberately fake binding hashes at [`test_loc_meshgrid_report.py:218`](/home/yixunhu/codespace/FLAC/src/tests/test_loc_meshgrid_report.py:218) currently normalize the missing join.

3. **BLOCKER — GT resolution is spoofable and can corrupt every distance metric.** [`TruthResolver.resolve`](/home/yixunhu/codespace/FLAC/src/localization/meshgrid_report.py:424) trusts an unbound live pair file. The checks authenticate only `rec_loc` at [`meshgrid_report.py:448`](/home/yixunhu/codespace/FLAC/src/localization/meshgrid_report.py:448) and scalar nearest-grid distance at [`meshgrid_report.py:517`](/home/yixunhu/codespace/FLAC/src/localization/meshgrid_report.py:517). Those are non-injective: two sources mirrored within a lattice cell can have the same receiver and identical `e_oracle`, yet different `e_loc`, success, baseline errors, and off-grid scores. The test intentionally moves GT so the oracle changes, leaving this case uncovered at [`test_loc_meshgrid_report.py:471`](/home/yixunhu/codespace/FLAC/src/tests/test_loc_meshgrid_report.py:471).

4. **BLOCKER — the off-grid tool accepts partial/non-merged runs and insufficiently joins rows.** [`assert_probe_binding`](/home/yixunhu/codespace/FLAC/src/localization/meshgrid_offgrid_probe.py:97) checks only strict binding fields; shards share that digest. It never verifies the 5,337-row census or merge report. Furthermore, [`load_grid_row`](/home/yixunhu/codespace/FLAC/src/localization/meshgrid_offgrid_probe.py:446) performs generic digest verification but never `assert_published_matches` or row-protocol checks. A same-binding wrong row at the expected path can silently supply another query’s grid scores to the ranks at [`meshgrid_offgrid_probe.py:540`](/home/yixunhu/codespace/FLAC/src/localization/meshgrid_offgrid_probe.py:540).

5. **BLOCKER — GPU work occurs before the binding gate.** AGREE is loaded onto `args.device` at [`meshgrid_offgrid_probe.py:655`](/home/yixunhu/codespace/FLAC/src/localization/meshgrid_offgrid_probe.py:655); binding verification occurs only at [line 661](/home/yixunhu/codespace/FLAC/src/localization/meshgrid_offgrid_probe.py:661).

6. **MAJOR — registered settings are not enforced.** [`assert_row_protocol`](/home/yixunhu/codespace/FLAC/src/localization/meshgrid_report.py:362) proves only row equals binding, not binding equals registered `tau=0.1`, `K={1,4,8}`, seed, noise, sampler, or checkpoint identities. Alternate bootstrap/baseline seeds are also only console-noted at [`meshgrid_report.py:1590`](/home/yixunhu/codespace/FLAC/src/localization/meshgrid_report.py:1590), while saved artifacts continue calling them pre-registered.

7. **MAJOR — “explained by float16 precision” is not established.** The `margin <= 2*deviation` arithmetic at [`meshgrid_report.py:575`](/home/yixunhu/codespace/FLAC/src/localization/meshgrid_report.py:575) is correct, and the row margin is independently derived, so an inflated recorded margin cannot excuse a flip. However, that inequality necessarily holds for every argmax flip between two vectors. There is no absolute float16 ULP bound or actual sidecar-dtype check; even strict mode accepts arbitrarily large divergence when the argmax remains unchanged. Thus `explained_by_precision` is overstated.

8. **MAJOR — registered latency aggregation is wrong/incomplete.** [`latency_report`](/home/yixunhu/codespace/FLAC/src/localization/meshgrid_report.py:789) pools global timings and denominators, with no room-first values or room bootstrap. Missing individual components are silently treated as zero at [line 801](/home/yixunhu/codespace/FLAC/src/localization/meshgrid_report.py:801), corrupting the registered latency endpoint.

9. **MAJOR — partial announcement-08 artifacts are possible.** Probe NPZs are finalized per query at [`meshgrid_offgrid_probe.py:526`](/home/yixunhu/codespace/FLAC/src/localization/meshgrid_offgrid_probe.py:526), before the all-16 completeness check at [line 554](/home/yixunhu/codespace/FLAC/src/localization/meshgrid_offgrid_probe.py:554) and final manifest at [line 688](/home/yixunhu/codespace/FLAC/src/localization/meshgrid_offgrid_probe.py:688). A later failure leaves unmanifested GT/waveform files, and the NPZ itself contains no control/subset/leakage labels.

10. **Minor result-label errors.**

   - Best-score ties have rank 1, but [`summarize_probe`](/home/yixunhu/codespace/FLAC/src/localization/meshgrid_offgrid_probe.py:367) counts them as “truth beats every candidate.”
   - The visualization rule promises the smaller global position for ties at [`meshgrid_report.py:100`](/home/yixunhu/codespace/FLAC/src/localization/meshgrid_report.py:100), but the highest-error selection chooses the largest tied position at [line 1057](/home/yixunhu/codespace/FLAC/src/localization/meshgrid_report.py:1057).
   - The Markdown model table omits mean `e_excess`; its random-baseline table omits both 1.0 m success columns, although JSON contains them.
   - Successful primary JSON/Markdown carry the requested disclosures, but the cases JSON and off-grid outputs omit `LATENCY_SCOPE_NOTE` and the outstanding sparse AGREE-retrieval control.

The core localization arithmetic, room bootstrap for localization/oracle/baseline metrics, SHA-256 random baseline keying, K=8 LME selection, common-random-number off-grid noise, and structural exclusion of truth scores from argmax candidate sets are otherwise sound.
