## 0. Target and base

- **Target repo:** `~/codespace/ORBITRIR`, branch **`main`** (origin `git@github.com:Yixun-Hu/ORBITRIR.git`, upstream `AmandineBtto/FLAC`; set by Yixun 2026-08-29), base `ead8bbd` = upstream master (already on `origin/main`).
- **Source of truth for the port:** FLAC fork at the B-F launch commit **`f59f5a4`** (2026-07-18) — the exact code state B-F trained with. Later FA-path changes (exp_11 batched orbit, exp_14 chunk cap, exp_15 yaw-aug, exp_16 ARE, exp_19 cyl routing, exp_21 fa_cartesian) are additions, not fixes, and are **excluded** (D6).
- **Method being ported (unchanged semantics):** `cond_method = "fa_invariant"` — (i) pose path: absolute `(x,y,z)` → yaw-invariant cylindrical `(r, z, Δφ)` relative to the source azimuth; (ii) ViT path: C4 frame average `(1/4) Σ_g f(g·x)` of the two DINOv3 depth-panorama conditioners, depth roll + `*_vit` pose rotation applied together per angle; all other conditioners run once. Training recipe: 2×GPU DDP + SyncBN, micro-batch 32 (BN batch 64 = paper), ViT gradient checkpointing, `--max-steps 67500`, DINOv3 revision `114c1379950215c8b35dfcd4e90a5c251dde0d32`.
- **Rev 3 additions beyond the as-run code (each is a fail-closed safety or provenance feature, none changes the numerics):** trained-as protocol guard in both eval entry points (C7c); shared conditioning dispatcher (C6, D11); pinnable HF `revision` (C1/C11, D10); documented inference API (C12).
